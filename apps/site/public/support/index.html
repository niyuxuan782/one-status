Before contacting us

Include enough non-sensitive detail to reproduce the problem:

  • The One Status, ChatGPT, Codex, or Desktop version involved.
  • The approximate time and timezone.
  • The tool name, visible error code, and expected result.
  • Whether an authorized One Status Desktop device was online.
Keep secrets out of support messages.

Do not send passwords, API keys, private keys, recovery material, OAuth tokens, cookies, MFA or OTP codes, or unredacted configuration files.

Public ChatGPT and Codex plugin

The first public plugin provides three read-only tools for Profile, Context, and confirmed Memory. It has no credential, external-service, device-control, or write tools.

device_offline

The requested Status view needs an authorized device that can decrypt it. Open One Status Desktop on a trusted device, confirm its background service is online, and retry.

Missing or old data

Open One Status Desktop and confirm the relevant Profile, active project, task, or Memory entry. Only confirmed memory is available to the public plugin; candidate observations and raw conversations stay excluded.

Unexpected tool request

Do not approve a scope or action you did not request. Disconnect One Status from the OpenAI product and contact support with the visible tool name and time.

OAuth, sign-in, and revocation

  • Confirm the authorization page is hosted under os.furesta.top.
  • For the first public plugin, approve only status:profile:read, status:context:read, and status:memory:read.
  • Complete the OAuth window in the same browser session that initiated the connection.
  • To disconnect, revoke One Status in the connected OpenAI product or One Status account controls.

Revocation blocks future access. A user can reconnect later and approve a fresh grant.

Privacy and account requests

Email support from the address associated with the account for access, correction, export, OAuth revocation, account closure, or deletion. State the request type and account email. One Status will verify control of the account before acting.

See the Privacy Policy for data categories, recipients, retention, and available controls.

Security reports

Send suspected vulnerabilities privately by email with "One Status Security" in the subject. Include affected URLs, impact, and safe reproduction steps. Avoid accessing other users' data or causing service disruption. Public disclosure should wait until a fix is available.

Open-source installation

Use GitHub Issues for installation failures, documentation gaps, and reproducible code defects that contain no private account data. Include the operating system, architecture, One Status version, installation method, and redacted logs.
