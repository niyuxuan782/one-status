KEY WALLET · E2EE

一个钥匙串，供所有设备和 Agent 使用

密钥钱包自动识别模型配置，也接收用户交给 Agent 的账号密码、SSH、云平台凭据、卡密、Token 和证书。条目在客户端加密后同步，云端只保存密文。

  1. 01自动扫描只读识别 Codex、Claude Code、CC Switch 与本机模型服务
  2. 02自动登记用户向 Agent 提供可复用凭据时，同轮加密写入钱包
  3. 03端到端同步账号、主机、用途与 Secret 随 E2EE Vault bundle 到达其他设备
  4. 04按需使用Agent 按服务、主机、账号、项目和用途选取；模型可以直接切换
  5. 05持续更新密码或 Token 轮换时更新原条目，所有读取留下脱敏审计

MEMORY

记忆在后台形成，决定权始终留给用户

后台记忆生成机制从明确记忆请求、项目文档、Handoff、Git 事实和重复习惯中提炼结构化候选。记忆页面统一完成确认、编辑、删除和类别控制。

  • 01 记录观察时间、来源 Agent、项目与置信度
  • 02 合并重复观察，持续更新出现次数
  • 03 原始会话默认留在本机

跨设备只同步经过 E2EE 的结构化记忆。后台生成机制不会出现在主导航中。
