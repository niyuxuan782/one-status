KEY WALLET · E2EE

扫描一次，让每台设备都能安全切换模型

密钥钱包自动识别 Agent 配置、Codex Providers、CC Switch Profile、Endpoint、协议、密钥引用和可配模型。条目在客户端加密后同步，云端只保存密文。

  1. 01扫描配置只读识别 Codex、Claude Code、CC Switch 与本机模型服务
  2. 02加密入库密钥、Endpoint 和模型能力进入 E2EE 钱包
  3. 03选择模型按设备与 AI 工具查看当前可用模型
  4. 04直接切换无需钱包密码，也不会把密钥明文交给 Agent
  5. 05查看密钥查看或复制明文时必须验证钱包密码

MEMORY

记忆在后台形成，决定权始终留给用户

后台记忆生成机制从明确记忆请求、项目文档、Handoff、Git 事实和重复习惯中提炼结构化候选。记忆页面统一完成确认、编辑、删除和类别控制。

  • 01 记录观察时间、来源 Agent、项目与置信度
  • 02 合并重复观察，持续更新出现次数
  • 03 原始会话默认留在本机

跨设备只同步经过 E2EE 的结构化记忆。后台生成机制不会出现在主导航中。
