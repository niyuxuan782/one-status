ONE USER · ONE STATUS

Agent 换了，工作现场还在

One Status 在本机发现环境资产，在云端只同步加密状态，通过 GitHub 交接项目内容。

01

发现本机环境

只读扫描 Codex、Claude Code、Git 仓库、Skills、MCP、Rules 和项目配置，确认后再导入。

02

同步加密状态

Memory、Preferences、Task State 和项目摘要在设备端加密，服务器保存 ciphertext 与同步元数据。

03

继续任何 Agent

Codex 与 Claude Code 从同一份 Status 恢复上下文，并通过受控权限调用 GitHub、Calendar 和 Slack。

HANDOFF

从一台设备的最后一步继续

程序采集 Git branch、commit、dirty state 和测试状态，生成可审计的 Handoff。Secret 扫描与用户确认通过后才会提交并推送。

  • ✓ 精确 Git commit 与文件 SHA-256
  • ✓ 本机绝对路径按设备独立保存
  • ✓ Continue with Codex / Claude Code

macOS Apple Silicon.dmg · M1 及更新机型 macOS Intel.dmg · Intel Mac Windows.exe · Windows 10/11 x64 Linux.AppImage · x64
SHA-256 校验

一条命令安装桌面版

脚本从 GitHub Release 下载产物，并使用同一 Release 的 SHA256SUMS 验证。

macOS / Linux
curl -fsSL https://os.furesta.top/install.sh | bash
Windows PowerShell
irm https://os.furesta.top/install.ps1 | iex
macOS App + CLI

Homebrew

Cask 安装桌面 GUI；Formula 安装 CLI、MCP 与常驻本机服务。

Desktop App
brew tap niyuxuan782/tap brew install --cask niyuxuan782/tap/one-status
CLI + Service
brew tap niyuxuan782/tap brew trust --formula niyuxuan782/tap/one-status 2>/dev/null || true brew install niyuxuan782/tap/one-status brew services start one-status
Node.js 22+
